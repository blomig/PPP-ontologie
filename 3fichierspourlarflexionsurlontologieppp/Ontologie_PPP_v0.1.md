# Ontologie PPP v0.1

## Objet

Cette ontologie a pour objectif de fournir un référentiel partagé des Propriétés Perceptuelles Pertinentes (PPP).

Elle est inspirée des travaux de Bence Nanay sur les propriétés pertinentes du point de vue esthétique, l'attention distribuée et le semi-formalisme. Son ambition n'est pas de produire des jugements esthétiques ni de mesurer objectivement la qualité d'un objet, mais d'offrir un langage descriptif permettant de qualifier les propriétés auxquelles l'attention peut se distribuer lors d'une expérience esthétique.

---

# Structure générale

Les propriétés sont organisées en trois familles :

1. Propriétés formelles
2. Propriétés semi-formelles
3. Caractéristiques attentionnelles

Chaque propriété comporte :

- Nom canonique
- Famille
- Définition
- Question attentionnelle
- Exemples
- Contre-exemples
- Relations principales

---

# Propriétés semi-formelles (noyau PPP)

## Densité perceptive

Définition : sentiment d'occupation de l'espace perceptif.

Question attentionnelle : l'espace perceptif apparaît-il chargé ou aéré ?

Exemples : amas, saturation visuelle, texture compacte.

Contre-exemples : vide, respiration, dispersion.

Relations : contraste, hiérarchie, segmentation.

---

## Intensité perceptive

Définition : degré selon lequel les propriétés sensibles sollicitent l'attention.

Question attentionnelle : dans quelle mesure l'expérience s'impose-t-elle à l'attention ?

Exemples : luminosité forte, texture saillante, volume sonore élevé.

Contre-exemples : discrétion perceptive, effacement.

Relations : saillance, contraste.

---

## Contraste perceptif

Définition : degré de différenciation perceptible entre éléments ou qualités.

Question attentionnelle : les différences apparaissent-elles douces ou marquées ?

Exemples : clair / sombre, lisse / rugueux.

Contre-exemples : homogénéité continue.

Relations : intensité, segmentation.

---

## Variation perceptive

Définition : degré de changement perceptible au cours de l'expérience.

Question attentionnelle : les propriétés restent-elles stables ou évoluent-elles ?

Exemples : rythme changeant, alternances, modulation.

Contre-exemples : stabilité uniforme.

Relations : régularité, continuité.

---

## Régularité perceptive

Définition : présence de motifs ou structures répétitives.

Question attentionnelle : observe-t-on des récurrences perceptibles ?

Exemples : motifs, trames, répétitions.

Contre-exemples : distribution aléatoire.

Relations : répétition, hiérarchie.

---

## Continuité perceptive

Définition : fluidité de l'enchaînement perceptif.

Question attentionnelle : la perception se déroule-t-elle comme un flux ou par fragments ?

Exemples : gradient, transition douce.

Contre-exemples : rupture, discontinuité.

Relations : variation, segmentation.

---

## Tension perceptive

Définition : maintien d'une sollicitation attentionnelle sans résolution immédiate.

Question attentionnelle : l'expérience suspend-elle ou maintient-elle l'attention ?

Exemples : équilibre instable, attente.

Contre-exemples : relâchement immédiat.

Relations : saillance, contraste.

---

## Hiérarchie perceptive

Définition : degré d'organisation des éléments en niveaux perceptifs.

Question attentionnelle : certaines parties dominent-elles clairement l'ensemble ?

Relations : centralité, organisation.

---

## Segmentation perceptive

Définition : facilité avec laquelle des sous-ensembles sont distingués.

Question attentionnelle : la scène paraît-elle découpée ou fusionnée ?

Relations : contraste, continuité.

---

## Organisation perceptive

Définition : manière générale dont les éléments sont structurés.

Question attentionnelle : la structure paraît-elle centralisée, distribuée ou diffuse ?

Relations : hiérarchie, centralité.

---

# Caractéristiques attentionnelles

## Saillance

Définition : facilité avec laquelle une propriété attire spontanément l'attention.

Valeurs : immédiate, progressive, latente.

---

## Distribution de l'attention

Définition : manière dont l'attention se répartit entre les propriétés.

Valeurs : focalisée, distribuée, oscillante.

---

## Régime d'exploration

Définition : temporalité selon laquelle les propriétés deviennent accessibles.

Valeurs : immédiat, progressif, émergent.

---

# Propriétés formelles (extensions possibles)

- Couleur
- Luminosité
- Texture
- Grain
- Saturation
- Épaisseur
- Matité
- Brillance
- Transparence
- Opacité

Ces propriétés pourront être spécialisées selon les domaines (matières, objets, interfaces, images, sons, espaces).

---

# Statut de l'ontologie

Cette ontologie est volontairement ouverte.

Aucune prétention à l'exhaustivité n'est revendiquée.

Une propriété peut être ajoutée si :

1. elle est perceptible ;
2. elle peut faire l'objet d'une attention distribuée ;
3. sa prise en compte peut modifier l'expérience de l'objet observé.
