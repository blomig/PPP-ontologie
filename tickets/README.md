# Tickets

Ce dossier reçoit les tickets recevables, convertis en fichiers (`tickets/<nnnn>-<type>.md`), après le jugement de recevabilité (voir `docs/gouvernance.md` et `CONTRIBUTING.md`). Il est vide au départ.

Pour ouvrir un ticket, utilisez les formulaires du dépôt : onglet *Issues*, puis *New issue*.
